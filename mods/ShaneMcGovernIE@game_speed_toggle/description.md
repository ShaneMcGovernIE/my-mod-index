# Game Speed Toggle

Cycle the engine's game speed between 1X, 2X, 4X and 10X with the
**9** key on keyboard, or **SELECT + LEFT BUMPER** together on gamepad.
The chosen speed rides the engine's own OPTIONS -> GAME SPEED row, so it
persists between sessions.

A small box in the top-left of the playfield shows the new speed for a
moment after each toggle.

## Install

1. Download `game_speed_toggle-<version>.zip` from the
   [releases page](https://github.com/ShaneMcGovernIE/game_speed_toggle/releases).
2. In the launcher: MODS → **Import mod .zip**.
