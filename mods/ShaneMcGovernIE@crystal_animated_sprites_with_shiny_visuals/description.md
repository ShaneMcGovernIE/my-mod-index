# Crystal Animated Sprites with Shiny Visuals

Crystal animated normal and shiny sprites combined with Gen 2-style
shiny sparkles.

## Install

1. Download `crystal_animated_sprites_with_shiny_visuals-<version>.zip`
   from the
   [releases page](https://github.com/ShaneMcGovernIE/crystal_animated_sprites_with_shiny_visuals/releases).
2. In the launcher: MODS → **Import mod .zip**.
