# Widescreen Battle Intro

Extends the battle intro's flash effect (wild encounters and stronger
foes) across a widescreen layout instead of the classic 160x144 box.

## Install

1. Download `widescreen_battle_intro-<version>.zip` from the
   [releases page](https://github.com/ShaneMcGovernIE/gen1recomp-widescreen-battle-intro/releases).
2. In the launcher: MODS → **Import mod .zip**.
