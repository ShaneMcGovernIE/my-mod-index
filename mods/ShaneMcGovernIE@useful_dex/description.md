# Useful Dex

On the Pokédex species data page, press **A** to cycle through the mon's
info pages:

1. **Data**: the vanilla page (sprite, kind, height/weight, description).
2. **Stats**: base stats (HP/ATK/DEF/SPD/SPC), their **BST** sum, and the
   species' evolutions: level, item, or trade method with the target name.
3. **Moves**: the full movelist: level-up learned moves first, then TM/HM
   compatibility.

## Install

1. Download `useful_dex-1.1.0.zip` from the
   [releases page](https://github.com/ShaneMcGovernIE/useful_dex/releases).
2. In the launcher: MODS → **Import mod .zip**.

With `"github": "ShaneMcGovernIE/useful_dex"` set, the launcher's **Update**
and **Versions** buttons handle new releases from there.
