# 999 Bag Slots - Test Fill

Test companion to `bag_999`: raises the bag to 999 slots and pre-fills
it with one of every item in the game on boot, so the capacity is
visible in one glance.

## What it does

- The bag holds the whole item catalog — on a vanilla 20-slot bag the
  game refuses at the 21st distinct item; here the full catalog is in
  the bag before you walk a step.
- Pairs with **bag_999** (999 Bag Slots).

## Install

Import the `.zip` from the GitHub release: MODS > Import mod .zip.
