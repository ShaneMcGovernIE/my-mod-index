# Pokémon Version Violette

Ports the data layer of the French romhack Pokémon Version Violette GBC
onto the Gen 1 recomp engine.

## Install

1. Download `violette-<version>.zip` from the
   [releases page](https://github.com/ShaneMcGovernIE/gen1recomp-violette/releases).
2. In the launcher: MODS → **Import mod .zip**.
