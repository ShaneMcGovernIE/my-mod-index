# Pokémon Cry Replacement

Replaces all 151 Pokémon cries with ones from the anime and from Fire
Red / Leaf Green, switchable on the fly in the options menu:

- **Original** — unchanged cries
- **Fire Red** — the GBA remake's cries
- **Anime** — cries from the anime TV show (files found on the PokeMMO
  forums, credits to Galladito/RojoY)

Video preview: https://youtu.be/Gb6nS47V0SE

## Install

Import the `.zip` from the GitHub release: MODS > Import mod .zip.
