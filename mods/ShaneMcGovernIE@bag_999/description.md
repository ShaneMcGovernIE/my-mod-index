# 999 Bag Slots

Raises the bag's capacity from 20 to 999 distinct item slots, so the
"This is too full!" refusal goes away. Each item still stacks to 99 per slot
(that cap is unchanged).

## Install

1. Download `bag_999-1.0.0.zip` from the
   [releases page](https://github.com/ShaneMcGovernIE/bag-999/releases).
2. In the launcher: MODS → **Import mod .zip**.

With `"github": "ShaneMcGovernIE/bag-999"` set, the launcher's **Update**
and **Versions** buttons handle new releases from there.
