# Useful Bag

Raises the bag's capacity from 20 to 999 distinct item slots and auto-sorts
the bag into six pockets — ITEMS, MEDICINE, POKé BALLS, TMs / HMs, BATTLE
ITEMS and KEY ITEMS — cycled with LEFT / RIGHT (wrapping around). A hidden
bag keeps the full inventory active underneath the pockets, so key items
work no matter which pocket the bag was closed on.

## Install

1. Download `useful_bag-2.0.0.zip` from the
   [releases page](https://github.com/ShaneMcGovernIE/useful-bag/releases).
2. In the launcher: MODS → **Import mod .zip**.

With `"github": "ShaneMcGovernIE/useful-bag"` set, the launcher's **Update**
and **Versions** buttons handle new releases from there.

## Controls

- LEFT / RIGHT in the bag cycle the six pockets (wrapping at both ends).
- TAB (keyboard) or R3 / right stick click sorts the bag by name or count.
- Shift keys still perform the vanilla SELECT item-swap.
