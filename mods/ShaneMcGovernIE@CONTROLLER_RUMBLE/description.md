# Controller Rumble

Controller rumble for Gen 1 shakes plus modern extras: battle
hits/heals/EXP, catching, and more.

## Install

1. Download `CONTROLLER_RUMBLE-<version>.zip` from the
   [releases page](https://github.com/masterwebx/gen1recomp-controller-rumble/releases).
2. In the launcher: MODS → **Import mod .zip**.
